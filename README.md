# Alexey Cherepanov — Personal Homepage

My personal website, built for CIS 4930 at FSU.

**Live site:** https://stormman77.github.io/homepage/

## What's on the page

- **About** — a short introduction and photo
- **Experience** — education, work, and projects
- **Toolkit** — languages, frameworks, and tools I use
- **Off the clock** — motorsport and aviation
- **Contact** — LinkedIn

It also has a light/dark theme toggle that remembers your choice, and a navigation bar that highlights the section you're reading.

## Built with

- React + TypeScript
- Vite
- Plain CSS, IBM Plex fonts
